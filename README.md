# Safe Air, Safe Place - Plataforma Web

Plataforma IoT para detección temprana de fugas de gas.

## 🌐 Demo en Vivo

Visita: [https://tu-usuario.github.io/safe-air-webapp/demo.html](demo.html)

## ✨ Características

- 🏠 Modo Demostración interactivo
- 📱 Responsive (móvil, tablet, desktop)
- ⚡ Simulación de fugas de gas
- 🎨 Interfaz profesional
- 📊 Dashboard con métricas en tiempo real
- ⚠️ Centro de alertas con protocolos de seguridad

## 🚀 Uso

### Online
Accede directamente a [demo.html](demo.html) desde tu navegador.

### Local
```bash
python -m http.server 3000
```

Luego abre: `http://localhost:3000/demo.html`

## 📋 Proyecto

Este es parte del proyecto MEP GLP IoT - experimento de arquitecturas de detección de gas con ESP32.

## 🔒 Seguridad

- Datos simulados claramente marcados
- Sin control automático de válvulas
- Protocolos de seguridad en alertas
- Solo para demostración educativa
